# Moving your accounts by hand

Use this guide if authexodus does not work for you, if you use an Android phone, or if you only have a few accounts. You move one account at a time. It is slow but it always works, and it needs nothing from Authy except that it keeps running until you finish.

## Before you start

1. Keep Authy installed and signed in on your device. Do not delete it until every account below is done.
2. Choose your new authenticator app and install it. Make sure it has its own backup or sync, so a lost phone does not lose your codes again.
3. Make a list of your accounts. Open Authy and write down each name.

## Order of work

Do the accounts that matter most first. If you run out of time, the important ones are safe.

1. Email accounts (they reset everything else).
2. Your password manager.
3. Banks, money and tax accounts.
4. Your phone, Apple, Google or Microsoft account.
5. Work accounts and cloud storage.
6. Social media, shopping and games last.

## For each account

1. Sign in to the account on its own website or app, using its usual password and the code from Authy.
2. Open Security (sometimes called Account, Login or Privacy) and find **Two-step verification**, **Two-factor authentication** or **2FA**.
3. Choose to set up, change or replace the **authenticator app**. If the service says it is already on, look for "Change authenticator", "Reset" or "Set up a new device".
4. The service shows a QR code. Scan it with your new app, then type the six-digit code from the new app to prove it works.
5. Save the new **recovery codes** the service shows. Store them in your password manager or print them. Old recovery codes may stop working.
6. Check it: sign out, sign in again, and use the code from the new app. Only then tick the account off your list.
7. Leave the old Authy entry alone for now.

## Authy's own 7-digit accounts

Some accounts (for example Twitch) show a seven-digit code in Authy. Authy made those itself, and they cannot be copied. Set each one up again the same way as above, in that service's security settings, choosing a standard authenticator app. The new code will have six digits.

## When all accounts are done

- Wait a week or two. Use each account at least once with the new app.
- Then remove accounts from Authy, or delete Authy. Do not do it sooner.

## If you get locked out

- Use a saved recovery code on the sign-in page.
- Otherwise use the service's account recovery page. It can take days. This is why Authy stays until the end.
